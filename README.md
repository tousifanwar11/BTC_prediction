# Bitcoin Price Prediction

This project aims to predict the price of Bitcoin using machine learning techniques. 

## Project Overview

Predicting the price of Bitcoin is a challenging task due to its volatile nature and the various factors that can influence its value. This project explores different machine learning models to forecast future Bitcoin prices based on historical data.

## Data

The project uses historical Bitcoin price data, potentially including:

*   **Opening price:** The price at which Bitcoin opens the trading day.
*   **Closing price:** The price at which Bitcoin closes the trading day.
*   **High price:** The highest price of Bitcoin during the trading day.
*   **Low price:** The lowest price of Bitcoin during the trading day.
*   **Volume:** The number of Bitcoins traded during the trading day.

The data can be sourced from various cryptocurrency exchanges or APIs.

## Methodology

The project explores different machine learning models for price prediction, including:

*   **Linear Regression:** A simple model that assumes a linear relationship between the features and the target variable.
*   **Support Vector Machines (SVM):** A powerful model that can capture non-linear relationships in the data.
*   **Recurrent Neural Networks (RNN):** A type of neural network that is well-suited for time series data, such as Bitcoin prices.
*   **Long Short-Term Memory (LSTM):** A type of RNN that can capture long-term dependencies in the data.

The project involves the following steps:

1.  **Data Collection:** Gathering historical Bitcoin price data.
2.  **Data Preprocessing:** Cleaning and preparing the data for modeling.
3.  **Feature Engineering:** Creating new features that may improve model performance.
4.  **Model Training:** Training the machine learning models on the historical data.
5.  **Model Evaluation:** Evaluating the performance of the models using metrics such as mean squared error (MSE) and R-squared.
6.  **Price Prediction:** Using the trained models to predict future Bitcoin prices.

## Usage

To use the project, follow these steps:

1.  Clone the repository.
2.  Install the required dependencies.
3.  Run the Python scripts to train and evaluate the models.
4.  Use the trained models to predict future Bitcoin prices.
